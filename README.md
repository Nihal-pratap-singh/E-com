

# 🛍️ Clothing E-commerce Website

A **full-stack clothing e-commerce platform** built with **MongoDB, Express.js, React.js, and Node.js (MERN)**, providing a seamless shopping experience for users to browse, search, and purchase clothing online.

---

## 🚀 Live Demo

🔗 **[View Live Project](https://e-com-frontend-6urd.onrender.com/)**

---

## 📌 Features

* **Responsive & Mobile-Friendly Design**
  Built with **React** and **Tailwind CSS** for smooth browsing on any device.
* **Product Catalog & Categories**
  Displays a wide range of clothing items with category-based filtering.
* **Search Functionality**
  Quickly find products by name or category.
* **Shopping Cart & Checkout**
  Add/remove products with dynamic pricing and quantity updates.
* **RESTful API Integration**
  Built APIs for products, users, and orders with **MongoDB Atlas** as the database.

---

## 🛠️ Tech Stack

* **Frontend:** React.js, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB Atlas
* **API:** RESTful API

## ⚙️ Installation & Setup

1️⃣ **Clone the repository**

```bash
git clone https://github.com/your-username/e-commerce-website.git
cd e-commerce-website
```

2️⃣ **Install dependencies**

**Frontend**

```bash
cd frontend
npm install
```

**Backend**

```bash
cd ../backend
npm install
```

3️⃣ **Set up environment variables** (in `backend/.env` file)

```
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
```

4️⃣ **Run the application**

**Backend**

```bash
cd backend
npm start
```

**Frontend**

```bash
cd frontend
npm run dev 
```
